Toys REST API

Base URL: http://localhost:3001. Requests and responses are JSON.

Getting started

  1. Sign up with POST /users (name, email, password).
  2. Log in with POST /users/login to get a token (valid for 60 minutes).
  3. Send the token in the x-api-key header on the routes marked "token".

Pagination

Lists return up to 10 toys. ?skip= is the page number: skip=0 (or no skip) is the first 10, skip=1 the next 10, and so on. Lists can also be sorted with ?sort= (name, category, price, createdAt; default _id) and ?reverse=yes.

Users

MethodPathTokenInfoBody
POST/usersno Sign up. The email must be unique (400 otherwise). The password is stored hashed and is not returned. 
{
  "name": "string, 2-100",
  "email": "valid email",
  "password": "string, 3-100"
}
POST/users/loginno Log in. Returns {"token": "..."}. 401 if the email or password is wrong. 
{
  "email": "valid email",
  "password": "string"
}

Errors

Errors are returned as JSON, usually {"err": "..."}. Validation errors return the Joi details array. 400 for invalid input, 401 for a missing, invalid or expired token, 403 when the toy belongs to another user, 404 when nothing is found, 502 on a database error.

Example

curl -X POST DOMAIN/users/login -H "Content-Type: application/json" \
     -d '{"email":"dana@example.com","password":"123456"}'

curl -X POST DOMAIN/toys -H "Content-Type: application/json" -H "x-api-key: TOKEN" \
     -d '{"name":"Robot","info":"Walking robot","category":"Vehicles","price":99}'

curl "DOMAIN/toys?skip=0"
